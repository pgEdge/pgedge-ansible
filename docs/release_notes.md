# Release Notes

The release notes describe each release of the pgEdge Ansible Collection in
detail. Each page covers the following:

- An overview of the release's main features.
- The steps for upgrading from the previous release, including changes that
  existing playbooks and inventories need.
- A full description of every change, and why it was made.

The [Changelog](CHANGELOG.md) lists the main changes in each release, and links
to the release notes for the full detail.

Release notes start with the release after v1.1.0. The Changelog describes
v1.1.0 and earlier releases.
